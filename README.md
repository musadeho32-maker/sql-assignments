# Week 2 SQL Assignment

## Overview
This repository contains my Week 2 assignment on retrieving and sorting data using SQL queries with the `sales` database.

## Database Setup
Before running the queries, import the provided `sales` database into MySQL Workbench or your MySQL server.

Select the database with:

```sql
USE sales;
```

## Assignment Questions
The `answer.sql` file contains queries to:

1. Retrieve payment check numbers, payment dates, and amounts.
2. Find orders with the status `In Process`, sorted by order date in descending order.
3. Retrieve Sales Representatives' first names, last names, and emails, sorted by employee number in descending order.
4. Retrieve all columns and records from the offices table.
5. Retrieve the five cheapest products, showing product names and quantities in stock.

## How to Run
1. Import the `sales` database into MySQL.
2. Open `answer.sql` in MySQL Workbench.
3. Execute the queries.
4. Review the results for each question.

## Files
- `answer.sql` — SQL queries for all five assignment questions.
- `README.md` — Project overview, setup instructions, and query descriptions.
